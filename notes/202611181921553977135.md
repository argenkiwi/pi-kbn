Pi (0.74–0.84) has no editor placeholder API. pi-kbn draws the "Proceed with next task" / "Resume current task" hint by subclassing CustomEditor: render() appends dim text to lines[1] (the first content line, after the inverse-video cursor) when getText() is empty, and handleInput() turns Tab on an empty editor into setText(hint). setEditorComponent replaces any other extension editor, so the factory is tagged with Symbol.for("pi-kbn.editor") and, if getEditorComponent() returns a foreign factory, pi-kbn falls back to a belowEditor widget hint instead of clobbering it. The hint must be gated on ctx.isIdle(), and refreshUI calls tui.requestRender() so the editor redraws on board changes.
